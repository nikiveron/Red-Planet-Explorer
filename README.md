# 🚀 Red Planet Explorer — симулятор управления дроном

**Статус:** Прототип  
**Жанр:** Симулятор / исследование  
**Платформа:** Windows  
**Движок:** Unity  

---

## 🧭 Цель проекта

Red Planet Explorer — проект, направленный на закрепление практических навыков работы с **физическим движком Unity**.

В рамках проекта реализовано управление дроном с использованием физики, а также интерактивные и опасные объекты, влияющие на игровой процесс.

---

## 🎮 Основной функционал

### 🚁 Управление дроном
- Перемещение дрона с использованием физики
- Ограничение максимальной высоты полёта
- Управление тягой дрона через компонент `DroneController`
- Зависимость поведения дрона от параметров физики

---

### ⚡ Энергетический объект
- Представлен в виде зеленой молнии с коллайдером в режиме **Trigger**
- При входе дрона в триггер:
  - Проверяется наличие компонента `DroneEnergy`
  - Вызывается метод `AddEnergy()` для пополнения энергии
  - Объект уничтожается после взаимодействия
- Логика реализована в скрипте `EnergyItem`

---

### ☠️ Опасное подвижное препятствие
- Куб с компонентом `Rigidbody` в режиме **Kinematic**
- Перемещается по заданным точкам маршрута
- Движение реализовано через `MovePosition()` в `FixedUpdate`
- При столкновении с дроном:
  - Проверяется наличие компонента `DroneDestructor`
  - Вызывается метод `Detonate()` для уничтожения дрона
- Логика разделена на два скрипта:
  - `DangerMove` — движение по маршруту
  - `DangerObject` — обработка столкновений

---

## 🗺️ Создание уровня 

### Реализовано:
- Использование **префабов** для:
  - энергетических объектов
  - опасных препятствий
- Балансировка расположения объектов:
  - зоны повышенного риска
  - зоны восстановления энергии
- Визуальное разделение объектов с помощью цветов:
  - энергия — яркие, привлекающие внимание цвета
  - препятствия — агрессивные оттенки
  - дрон — контрастный, хорошо читаемый цвет
